# Personal Portfolio Website

### IT Support | Data Analytics | Business Intelligence

**Live Website:** [View My Portfolio](https://gullible-good-natured-salamander-m7ia7x.teleporthq.site/)

## Project Overview

I designed and developed a personal professional portfolio website to showcase my transition from more than 18 years in transportation, logistics, and warehouse operations into information technology and data analytics.

The website brings together my technical training, professional experience, projects, certifications, and problem-solving approach.

## Project Features

- Responsive, dark-themed portfolio design
- Cosmic-inspired background and animated comet effects
- Custom electric-blue and teal visual styling
- Animated circuit-inspired portrait frame
- Interactive navigation and professional story
- Technical skills and certifications showcase
- Project demonstrations and professional contact information

## Tools & Technologies

- TeleportHQ — Website design and development
- AI-assisted development — Design refinement, content creation, and troubleshooting
- GitHub — Project documentation and version control

## Development Process

1. Planned the website structure and professional content.
2. Developed a consistent cosmic-inspired visual design.
3. Created individual sections for experience, skills, training, and projects.
4. Added animations and interactive website elements.
5. Tested navigation, fixed visual glitches, and refined the final presentation.
6. Published the website through TeleportHQ.

## What I Learned

This project strengthened my skills in website design, iterative development, AI-assisted problem solving, visual communication, troubleshooting, and user experience.

I learned how to identify issues, test solutions, evaluate results, and improve a functional digital product.
